# Comércio 360 no Gemini Code Assist

Antes de qualquer tarefa de desenvolvimento, leia `AGENTS.md` e `context.md`. Confirme no Git o estado real da árvore e abra somente os documentos e arquivos necessários ao objetivo. Para tarefas do harness, consulte `docs/ai/PLANO_ORQUESTRACAO.md` e `docs/ai/CONTRATOS_HARNESS.md` conforme o escopo.

Atue como especialista ou revisor com objetivo, base, fontes, arquivos permitidos e critérios explícitos. Devolva fatos com referência, verificações executadas e limites; use `not_run` quando não houver execução. Não trate a proposta do Catálogo 002 como implementação autorizada. Não leia nem copie `.env*`, credenciais, tokens ou chaves para prompts e relatórios.

Gemini no VS Code é uma rota separada do Codex e do DSH. Uma resposta de Gemini não aprova integração nem substitui os testes e a revisão do orquestrador. O modelo efetivo deve ser confirmado no seletor do Gemini Code Assist antes de registrar uma avaliação comparativa.
